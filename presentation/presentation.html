Concepto

Una API es un contrato de comunicación

Define qué puede solicitar un cliente, cómo debe enviar la petición y qué respuesta recibirá.

PeticiónEl cliente indica la operación y envía los datos necesarios.
EndpointLa API define la ruta, el método y las reglas de entrada.
RespuestaEl servidor devuelve un estado HTTP y los datos acordados.

La API no es la pantalla ni la base de datos: es el punto de acceso al backend.

Definir API como contrato. La clave es que cliente y servidor pueden cambiar internamente mientras respeten ese contrato.

Separación de responsabilidades

Frontend presenta; backend procesa

Frontend

Se ejecuta en el navegador.

  • Recibe la interacción del usuario.
  • Envía peticiones al API.
  • Presenta la respuesta.
API

Backend

Se ejecuta en el servidor.

  • Valida la petición.
  • Ejecuta la lógica y accede a datos.
  • Devuelve una respuesta consistente.

En este proyecto Vue se ocupa de la interfaz y FastAPI del procesamiento de la imagen.

Separar responsabilidades. El frontend no ejecuta K-means y el backend no decide cómo se dibuja la paleta.

Analogía

La API funciona como el mesero

Fuente de la imagen: LinkedIn

El cliente elige usando el menú. El mesero recibe un pedido válido, lo lleva a la cocina y devuelve el resultado. El cliente no necesita entrar a la cocina ni conocer su implementación.

Errores HTTP

Qué pasa cuando una petición falla

1 / REQUEST Postman envía un archivo imagen: documento.pdf

La petición llega a POST /api/v1/palettes.

2 / VALIDACIÓN La API revisa el archivo application/pdf

El MIME no corresponde a JPEG, PNG o WebP. K-means no se ejecuta.

3 / RESPONSE 415 unsupported_media_type

La API rechaza la petición y explica el motivo.

HTTP 415

Indica al cliente qué ocurrió a nivel HTTP.

error.code

Permite tomar decisiones sin comparar mensajes.

error.message

Explica el problema a una persona.

error.request_id

Relaciona la respuesta con los logs de la API.

Agrupamiento de colores

Cómo funciona K-means

1

Leer

Cada píxel se representa con sus valores rojo, verde y azul.

2

Comparar

El algoritmo mide qué píxeles tienen colores parecidos.

3

Agrupar

Los píxeles similares se reúnen en la cantidad de grupos solicitada.

4

Resumir

Cada grupo produce un color representativo y un porcentaje.

Ejemplo: si solicitamos 5 colores, K-means divide los píxeles en 5 grupos y la API devuelve un color por grupo.
