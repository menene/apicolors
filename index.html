Proceso

Flujo de procesamiento

Desde la carga de la imagen hasta la paleta final con el porcentaje de cada color.

01 / UPLOAD

Cargar imagen

El usuario selecciona un archivo JPEG, PNG o WebP.

02 / API

Recibir y validar

FastAPI comprueba el formato, el tamaño y la cantidad solicitada.

03 / IMAGE

Preparar píxeles

Pillow corrige la orientación, convierte a RGB y reduce la imagen.

04 / K-MEANS

Agrupar colores

K-means agrupa píxeles similares y calcula su frecuencia.

05 / RESULT

Mostrar resultados

Vue presenta los colores dominantes con HEX, RGB y porcentaje.
